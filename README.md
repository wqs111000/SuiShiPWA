# 岁时 PWA

免费、长期可用的网页应用版本。把这个目录部署到任意 HTTPS 静态托管（GitHub Pages、Cloudflare Pages、Netlify 等），然后在 iPhone Safari 中打开，点“分享 → 添加到主屏幕”。

## 功能

- 公历与规范中文农历（日名使用“初一、十一、廿一”等）
- 2026 年国务院安排的法定休息日与调休上班日（格子显示“休/班”）
- 传统节日、现代节日、纪念日与二十四节气标记
- 月视图节日/节气清单、当日文化说明、年内天数与周数
- 倒数日、纪念日、生日和普通事项
- 剩余/已过去天数、每年重复
- 浏览器本地存储、深色模式、离线缓存
- iOS 16.4+ 主屏幕网页通知权限入口

## 限制

数据只存在当前浏览器；2026 年“休/班”依据国务院办公厅公告录入，2026 年节气日期已单独核对，其他年份使用常见日期参考且不推断法定调休。PWA 没有原生桌面 Widget、Siri/快捷指令和可靠的离线定时本地通知。若需要这些系统能力，请使用旁边的 SwiftUI 原生版本。
